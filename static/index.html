How it works

  • Uses SteamPrefill, running on this machine. It downloads through the cache and throws the data away, so the cache keeps a copy.
  • It needs a Steam account that has CS2 in its library (launch CS2 once on that account). The first run asks for the username, password and a Steam Guard code: type them in the box under the output. After that the login is remembered; the password is never saved.
  • Preload the night before, then press it again whenever the UPD lamp lights up during the event.
  • The cache must be running, or the download goes nowhere.

Storage: where the cache keeps game data

Tick the disks to use.

Selected disks are combined into one volume (LVM) mounted at /srv/lancache: game data in /srv/lancache/cache, logs in /srv/lancache/logs. Disks added later grow the same volume without losing cached games. The system disk can't be picked. Old cache data in the previous folder is left where it is.
